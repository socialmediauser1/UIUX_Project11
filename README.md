What I Learned

1. **Creating Data Objects**
- Learned how to structure data using an array of objects.
- This helped me understand how to organize data for dynamic rendering.

---

2. **Rendering Cards Dynamically**
- Used JavaScript to loop through the array of objects and dynamically create HTML elements.
- Learned how to append these elements to the DOM using `document.createElement` and `appendChild`.
- This taught me how to work with the DOM tree and dynamically inject content into a webpage.

---

3. **Adding Event Listeners**
- Added interactivity to the cards by using `addEventListener`.
- Implemented a feature where clicking a card highlights it by toggling a CSS class.
- This helped me understand how to handle user interactions and dynamically update styles.

---

4. **Using Array Methods**
- Practiced using array methods like `.reduce()`, `.sort()`, `.filter()`, and `.map()`:
  - **Reduce**: Calculated the total number of characters in all card titles.
  - **Sort**: Sorted the cards alphabetically by title.
  - **Filter**: Found cards with specific keywords in their descriptions.
  - **Map**: Created a new array containing only the titles of the cards.
- This improved my understanding of how to manipulate and process data in JavaScript.
